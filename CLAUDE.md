# Instructions for this repository

- Typography (fonts, sizes, weights; tables, plots and canvas included) follows @TYPOGRAPHY.md.
- All domain data (drug, molecular, receptor, route, regional and model data, numbers and descriptive texts) live in `assets/data/properties.json` (single source; units in its `meta`). Never hard-code such data in `js/` or HTML; add it to the JSON and read it from `window.AP` after `AP.load()` (`js/data.js`). Presentation settings (colors, layout, animation) stay in the code.
- Every new or changed value gets an entry in `sources` (references checked against PubMed or DailyMed, value reported in the source, status); run `python3 tools/check_sources.py` after data changes.
- If the local, git-ignored folder `manuscript/` exists, keep it in step with changes to data, models or validation as described in `manuscript/INSTRUCTIONS.md`.
- User-facing text is never hard-coded: static HTML text has a `data-i18n` key, and JavaScript uses `AP.t('key', vars)`; add every new key to both `assets/i18n/en.json` and `assets/i18n/sv.json`. Name keys by section and meaning (e.g. `mechanism.resetTip`, `pk.profileTitle`, `notes.pharmacokineticModel`; suffixes `Title`, `Intro`, `Label`, `Tip` for headings, introductions, form labels and tooltips), never by number. Descriptive texts of `properties.json` are translated in the `data` section of `sv.json` by path. Display numbers with `AP.fmt()` (decimal comma in Swedish) and concentrations with `AP.concUnit()`.
- English texts (interface, data descriptions, documentation, code comments and identifiers) use American English: color, gray, center, -ize/-ization, analyze, signaling, modeled, labeled, behavior, hyperprolactinemia, diarrhea, esophageal, norepinephrine. Keep the original spelling only in quoted titles of references and in proper names (e.g. McConnell Brain Imaging Centre). This holds in every region (EU and SE included); Swedish texts live in `sv.json`.
- Logic must not depend on translated text: parse or compare the English original in `AP.raw` (or use keys), never the displayed string.
- Region-specific values (US base, EU overlay in `jurisdictions.eu.data`, SE inheriting EU with nmol/L) need a source each; EU values come from the SmPC as published in FASS. Convert displayed plasma concentrations with `AP.conc(value, mw)` using the molecular weight of that species (parent or metabolite).
- Always keep the `.claude/` folder (Claude Code settings) outside the repository, in the parent folder `../.claude/`; never create it in or commit it to this repository. If it appears here, merge its settings into `../.claude/settings.local.json` and remove it from the repository. It is listed in `.git/info/exclude` (local, not in `.gitignore`) so it can never be committed; Claude Code recreates it while a session runs from this folder.
